# hello

Colonne de gauche du login Authentik (`auth.cocollet.ch`, mise en page *Sidebar right (frame background)*) et de
l'écran « Accès réservé » de status.cocollet.ch : la mascotte « Bonjour », dont les yeux suivent la souris, et le slogan.
Servie par GitHub Pages : https://cocollet.github.io/hello/

Couleurs : `tokens.css` de la charte (dépôt `Cocollet/brand`, même origine `cocollet.github.io`). Une couleur changée
là-bas s'applique ici sans toucher ce dépôt. Le dessin de la mascotte reste dans `index.html` : ses yeux sont animés
par le script de la page.

⚠️ Doit rester sur une autre origine qu'`auth.cocollet.ch` : l'iframe n'est pas isolée.
